# CoWorkHub — Backend Spring Boot

El backend forma parte del proyecto completo. Para ejecutar backend + MySQL + frontend, sigue las instrucciones del archivo `../README.md` y ejecuta `docker compose` desde la carpeta raíz del proyecto.

Tecnologías: Java 21, Spring Boot, Maven, Spring Data JPA, MySQL 8.4, Spring Security, JWT, BCrypt, Validation, Actuator y Springdoc OpenAPI.

Para abrir el backend en IntelliJ IDEA, selecciona esta carpeta (`backend`) como proyecto Maven. La ejecución integrada recomendada para evaluación es mediante el Docker Compose de la carpeta raíz.

El script `src/main/resources/import.sql` incluye cuentas de demostración con datos sintéticos. No utilices esas cuentas ni esos datos en un entorno real.
